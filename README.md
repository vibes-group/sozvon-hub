# sozvon-hub

Видеозвонки по одноразовой ссылке. Self-hosted: один сервер со встроенными SFU и TURN, без внешних медиасерверов и зависимостей.

## Возможности

- **Комната по ссылке.** Зарегистрированный пользователь создаёт комнату и делится одноразовой ссылкой — по ней заходит любой, без аккаунта.
- **Аккаунты по приглашениям.** Регистрация только по инвайт-ссылке от существующего пользователя.
- **Медиа.** Аудио с шумоподавлением, видео с камеры, демонстрация экрана.

## Разработка

```bash
docker compose -f docker-compose.dev.yml up -d --build
```

Приложение доступно на `http://localhost:8080`.

Фронтенд с HMR — отдельно от контейнера:

```bash
docker compose -f docker-compose.dev.yml up -d app --build
cd frontend && npm install && npm run dev
```
